# PLP Data Analysis Assignment 2: Rainfall Advisory

- This project cleans monthly rainfall readings for five counties and analyses rainfall patterns using NumPy.
- Run `rainfall_analysis.ipynb` from top to bottom in Jupyter Notebook or JupyterLab after installing dependencies with `pip install -r requirements.txt`.
- The planting advisory flags months with at least 100 mm of recorded rainfall as potential planting windows; confirm these screening results with local agronomic guidance and current conditions.
